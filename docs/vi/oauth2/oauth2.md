# Đăng nhập OAuth2

## Ví dụ với GitHub

1. Tạo một OAuth app tại https://github.com/settings/applications/new

2. Đặt địa chỉ callback là `https://<tên-miền-tùy-chỉnh-của-worker>/login`

<img src="../../public/images/oauth2/github-oauth1.png" class="article-img" />

3. Sau khi tạo khóa, thêm vào trong Cài đặt hệ thống
